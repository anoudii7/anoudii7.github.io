# موقع السيرة الذاتية – العنود المطيري

موقع شخصي يعرض مهاراتي ومشاريعي في الأمن السيبراني والبرمجة.

## هيكل المجلد
```
anoud-portfolio/
├── index.html      ← محتوى الصفحة (النصوص والأقسام)
├── css/style.css   ← التصميم والألوان والحركات
└── js/script.js    ← الحركات التفاعلية (العنوان، العدّاد، الأسئلة، المؤشر)
```

## التشغيل
افتحي `index.html` في المتصفح.

## النشر على GitHub Pages
1. أنشئي مستودع باسم `anoudii7.github.io`
2. ارفعي كل محتويات المجلد
3. الموقع يصير على: https://anoudii7.github.io
